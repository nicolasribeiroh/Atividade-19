# Projeto3aAPI

API REST de produtos (Spring Boot 3 + PostgreSQL) - Sistemas Distribuidos e Mobile.

| Ambiente | URL |
|---|---|
| Local (Atividade 20) | http://localhost:8081/produtos |
| Render (Atividade 18) | https://SUA-API.onrender.com/produtos |

Endpoints: GET/POST /produtos, GET/PUT/DELETE /produtos/{id},
/actuator/health, /actuator/info, /actuator/metrics.

Rodar local: `mvn spring-boot:run` (PostgreSQL local com banco `projeto3aapi`).
