# produtos-frontend

Frontend (HTML/CSS/JS servido pelo Spring Boot) do cadastro de produtos.

| Ambiente | Frontend | API usada |
|---|---|---|
| Local (Atividade 20) | http://localhost:8080 | http://localhost:8081/produtos |
| Render (Atividade 19) | https://SEU-FRONT.onrender.com | https://SUA-API.onrender.com/produtos |

A escolha da API e automatica (ver topo do `static/script.js`).
